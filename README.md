# Projetos pessoais em Python

Dois projetos de terminal para praticar lógica de programação, funções e validação de entradas em Python.

## Calculadora

O arquivo `calculadora.chat.py` permite somar, subtrair, multiplicar e dividir dois números. Valida entradas numéricas, impede divisão por zero e permite realizar novas operações.

```sh
python calculadora.chat.py
```

## Jogo de adivinhação

O arquivo `jogo.de.advinhação.py` sorteia um número e oferece até dez tentativas, com dicas para números maiores ou menores. Há três dificuldades: de 1 a 100, de 1 a 500 e de 1 a 1000.

```sh
python "jogo.de.advinhação.py"
```

## Como executar

Instale o Python 3, baixe ou clone este repositório e execute um dos comandos acima na pasta dos arquivos. Os programas utilizam apenas a biblioteca padrão do Python, sem dependências adicionais.
